# 筋肥大ブロック(週4・5週サイクル)

目的:筋量を保ちながら(減量中)/増やしながら(増量中)、BIG3を去年の水準へ戻す。BIG3の頻度は保ち、総ボリュームで筋肉に刺激を入れる。長期計画は [ROADMAP.md](ROADMAP.md)。

- 頻度:SQ 週2 / BP 週3(10/8/5プログラム) / DL 週1+RDL
- メインの強度:RPEで決める(重量は前回のe1RMから `summary.py` の値で逆算)
- 構成:4週かけてRPEを上げ、5週目はディロード。終わったら新しいe1RMで次サイクルへ

## BP:10/8/5プログラム(うつベンチ)

BPはこのプログラムだけを週3回、各4セットで行う(2026-11-05から)。下のRPE表はSQ・DLにだけ使う。

- 4セットとも目標レップを完遂したら、次回は **+2.5kg**(レップ数はそのまま)
- 1セットでも目標レップに届かなかったら、次回は **重量そのまま・レップを1段下げる**(10 → 8 → 5)
- 例:95×10×4 クリア → 97.5×10×4 失敗 → 97.5×8×4 クリア → 100×8×4 …
- 5レップで失敗したら10レップに戻し、重量は「そのサイクル最初の10レップの重量 +5kg」から再スタート(例:95kgで始めたサイクルなら次は100×10×4)
- 開始時点:10レップ日 95kg×10×4(11/5)

## 進め方のルール
- 補助種目はすべて3セットまで(2026-11-09変更:4セットはきつかったため)
- **BIG3**:その週のRPEに合う重量を、前週のe1RMから決める。同じRPEで前回より重い重量か、多いレップでこなせれば進歩。
- **補助種目**(ダブルプログレッション):全セットでレップ範囲の上限に届いたら、次回は重量を上げる(上半身 +1〜2.5kg、下半身 +2.5〜5kg)。
- **疲労の目安**:同じ重量が2週続けてRPE+1以上重く感じる場合や、睡眠が6時間を切る日が続く場合は、そのセッションの補助種目を1セットずつ減らす。
